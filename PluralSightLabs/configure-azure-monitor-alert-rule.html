Overview

Azure Monitor activity log alert rules trigger notifications when specific control-plane operations occur on Azure resources. In this lab, I used Azure CLI in Cloud Shell to create an action group with SMS notification and an activity log alert rule scoped to a storage account — configured to fire whenever a write operation is performed on that account. I then verified the alert rule appeared in the Azure portal's Alert rules blade.

What I Did

  • Opened Azure Cloud Shell in Bash mode with an ephemeral session and set environment variables for the resource group name and storage account resource ID
  • Created an action group (my-agl) with an SMS receiver using Azure CLI: 
    az monitor action-group create \
--name $action_group_name \
--short-name $action_group_name \
--resource-group $resource_group_name \
--action sms <name> 1 <phone>
  • Created an activity log alert rule (myalertrule3) scoped to the storage account, triggering on Administrative category write operations: 
    az monitor activity-log alert create \
  --name "myalertrule3" \
  --resource-group $resource_group_name \
  --scope $rule_scope \
  --condition "category=Administrative and operationName=Microsoft.Storage/storageAccounts/write" \
  --description "my description" \
  --action-group $action_group_name
  • Listed all activity log alerts to confirm creation: az monitor activity-log alert list
  • Navigated to the storage account's Alerts blade in the Azure portal and confirmed the alert rule appeared under Alert rules
