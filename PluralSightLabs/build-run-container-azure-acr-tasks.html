Overview

Azure ACR Tasks enable building, pushing, and running containers entirely in the cloud without requiring Docker installed locally. In this lab, I used Azure Cloud Shell to create a container registry, authored a minimal Dockerfile, built and pushed a container image to ACR using ACR Tasks, and ran the container directly from the registry — completing the full container lifecycle without any local Docker dependency.

What I Did

  • Opened Azure Cloud Shell in Bash mode, mounted an existing storage account, and created a new file share named "fileshare"
  • Created a new Azure Container Registry (acrbuildcontainer11) with Basic SKU and admin credentials enabled: 
    az acr create --resource-group <rg> \
--name acrbuildcontainer11 --sku Basic --admin-enabled true
  • Changed to the clouddrive directory and created a minimal Dockerfile using the hello-world base image: 
    echo "FROM hello-world" > Dockerfile
  • Built the image and pushed it to ACR using ACR Tasks — no local Docker daemon required: 
    az acr build --image sample/hello-world:v1 --registry acrbuildcontainer11 \
--file Dockerfile .
  • Verified the sample/hello-world repository appeared in the container registry under All resources in the Azure portal
  • Ran the container directly from the registry using ACR Tasks: 
    az acr run --registry acrbuildcontainer11 \
--cmd '$Registry/sample/hello-world:v1' /dev/null
