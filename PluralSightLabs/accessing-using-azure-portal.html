Overview

The Azure portal is the primary web-based interface for managing Azure resources. In this introductory lab, I explored the portal's core navigation elements, customized its appearance, located a storage account using the search bar, and worked with the dashboard system — adding a Metrics tile to an existing dashboard and creating a new dashboard from the Azure Inventory template, then publishing it and reviewing sharing options.

What I Did

  • Reviewed the top menu bar components: the hamburger menu, Microsoft Azure home button, Quick Search bar, Cloud Shell icon, Notifications, and Settings
  • Opened Settings and changed the Menu behavior to Docked and applied a custom theme to familiarize with appearance customization options
  • Used the search bar to locate Storage Accounts and explored the relationship between the left service menu and the top action menu bar at both the service list and individual resource levels
  • Opened the Dashboards interface, entered Edit mode, and dragged a Metrics Chart tile from the Tile Gallery onto the dashboard
  • Configured the Metrics Chart by scoping it to the lab storage account and selecting Used Capacity as the metric, then saved the chart to the dashboard
  • Created a new dashboard from the Azure Inventory template, named it "my-inventory", and submitted it
  • Published the dashboard using the Share option and reviewed the Access Control sharing options available in a production environment
