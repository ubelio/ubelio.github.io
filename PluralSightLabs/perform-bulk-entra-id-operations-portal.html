Overview

Microsoft Entra ID supports bulk operations via CSV templates, enabling administrators to create, delete, and manage users and group memberships at scale without performing each action individually. In this lab, I used the Bulk operations menu in the Entra ID portal to bulk create three users via CSV upload, bulk delete one of those users, create a security group, and bulk import a user as a group member — covering the full lifecycle of CSV-driven identity management operations.

What I Did

  • Copied the tenant's primary domain from the Microsoft Entra ID overview for use in CSV user principal names
  • Downloaded the bulk create CSV template (UserCreateTemplate.csv), appended three user rows (Lou Red, Chris Blue, Allister Green) with UPNs, passwords, and trailing commas for optional fields, then uploaded and submitted the file — confirmed all three users appeared in the All Users list after the bulk operation succeeded
  • Downloaded the bulk delete CSV template (UserDelete.csv), appended Chris's UPN, uploaded and confirmed deletion — verified Chris no longer appeared in the user list
  • Created a new Security group named "PrimaryColorTeam" in the Groups blade
  • Downloaded the bulk import group members CSV template (GroupImportMembersTemplate.csv), appended Lou's UPN, uploaded and submitted — confirmed Lou appeared as a member of PrimaryColorTeam after the operation succeeded
  • Noted key CSV formatting requirements: no spaces between commas and field data, trailing commas required for all optional fields, and template field counts may change over time — validate against the downloaded template before each use
