Overview

Azure Cost Management + Billing provides the tools organizations need to monitor spending, enforce budgets, and identify optimization opportunities across their Azure subscriptions. In this lab, I explored the three core interfaces for cost governance: the subscription-level Cost Management + Billing overview, the Budgets blade for setting spending thresholds, and the resource group Cost Analysis view for forecasting and analyzing resource costs within a defined scope.

What I Did

  • Navigated to Subscriptions and identified the subscription overview page as the starting point for billing and cost visibility at the subscription level
  • Opened Cost Management + Billing from the search bar, identifying it as the primary hub for managing costs and billing across the organization's Azure subscription
  • Navigated to the Budgets blade, identifying it as the interface for creating and managing spending budgets with alert thresholds — noting where budget configuration would take place in a production environment
  • Navigated to the resource group's Cost Management section and opened Cost Analysis, identifying it as the tool for reviewing actual and forecasted resource costs within a scoped resource group — useful for department-level chargebacks and spend forecasting
