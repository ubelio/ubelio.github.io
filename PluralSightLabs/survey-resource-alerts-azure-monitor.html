Overview

This lab covers navigating Azure Monitor to survey deployed resources and identify monitoring gaps, warnings, and advisories across virtual machines, storage accounts, containers, and networks. It concludes with enabling Application Insights on an App Service to extend observability coverage.

Section 1 — Navigate Azure Monitor

  • Opened Azure Monitor from the portal search bar
  • Reviewed the Insights section
  • Confirmed no Application Insights apps were present

Section 2 — Review Virtual Machine Monitoring

  • Selected Virtual Machines under Insights
  • On the Overview tab, identified one VM under the "Not monitored" tab with no Monitor coverage enabled

Section 3 — Review Storage Account Metrics

  • Selected Storage accounts under Monitor
  • Reviewed the Capacity tab
  • Drilled into the storage account for detailed metrics and insights

Section 4 — Review Network Resources

  • Selected Networks under Monitor
  • Confirmed one network interface, one virtual network, one network security group, one public IP, and no active alerts
  • Reviewed Connectivity (no results) and Traffic (one NSG) tabs

Section 5 — Survey All Resources

  • Navigated to All Resources from the Azure home page
  • Confirmed seven provisioned resources across the subscription

Section 6 — Enable Application Insights

  • Located the App Service (name beginning with webapp)
  • Under Settings, selected Application Insights
  • Clicked Turn on Application Insights
  • Left defaults and clicked Apply
  • Confirmed the deployment validation failed message — expected behavior in the lab sandbox environment
