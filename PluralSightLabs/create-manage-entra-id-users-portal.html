Overview

Microsoft Entra ID is the centralized identity and access management platform for Azure. These three Pluralsight labs cover the full user and group lifecycle: creating and modifying users, managing group membership and ownership, performing bulk identity operations via CSV, resetting passwords, revoking sessions, and deprovisioning users — the foundational IAM skills every Azure administrator needs.

Lab 1 — Create and Manage Microsoft Entra ID Users

  • Created three users (RP One, RP Two, RP Three) and confirmed all appeared in the Users list
  • Edited RP One's profile properties: set first/last name, job title (Helpdesk Technician), and department (IT Helpdesk)
  • Reset RP One's password, generating a temporary password requiring change on next sign-in
  • Revoked all active sessions for RP One using Revoke sessions, immediately invalidating current sign-ins
  • Deleted RP Three, confirmed removal from All Users, then verified it appeared in the Deleted Users 30-day retention list with Restore and Delete permanently options available

Lab 2 — Create a Group, Add Members, and Assign Ownership

  • Created a Security group named "Internship Program" with a descriptive group description covering both mentors and mentees
  • Added the pre-existing Cloud Student user as a member of the group
  • Created a new user (cloudinternmentor / Cloud Intern Mentor) and assigned them as the group owner — establishing distinct member and ownership roles within the same group

Lab 3 — Create and Organize Users and Groups for Access Control

  • Created three users (User1, User2, User3) with auto-generated passwords and accounts enabled
  • Created a Security group named "Project-Readers" with User1 as its sole member
  • Created a Security group named "Project-Contributors" with User2 and User3 as members
  • Verified both groups in All Groups, removed a member using the ellipsis action menu, and confirmed removal via page refresh
  • Deleted a user from the Users list, completing the identity lifecycle from creation through deprovisioning
