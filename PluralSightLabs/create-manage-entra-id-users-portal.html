Overview

Microsoft Entra ID is the centralized identity and access management platform for Azure, and managing user accounts is one of the most fundamental administrative tasks. In this lab, I walked through the full user account lifecycle: creating multiple users, modifying profile and job information, resetting a password, revoking active sessions, deleting a user, and verifying the 30-day soft-delete retention in the Deleted Users view.

What I Did

  • Created three Microsoft Entra ID users (RP One, RP Two, RP Three) using the Create new user flow and confirmed all three appeared in the Users list
  • Opened RP One's profile and edited properties: set First name, Last name, Job title (Helpdesk Technician), and Department (IT Helpdesk) across the Identity and Job Information tabs, then saved
  • Reset RP One's password using the Reset password action, generating a temporary password requiring change on next sign-in
  • Revoked all active sessions for RP One using Revoke sessions, immediately invalidating any current sign-ins
  • Deleted RP Three from the Users list, confirmed the account no longer appeared in All Users, then navigated to Deleted Users and confirmed RP Three appeared in the 30-day soft-delete retention list
  • Noted that Restore users and Delete permanently options are available from the Deleted Users view for accounts still within the retention window
