Overview

Azure Monitor and Activity Log together provide visibility into control-plane operations across an Azure environment. In this lab, I created an alert rule scoped to the subscription that fires when a Virtual Machine is deleted, triggered the alert by deleting a lab VM, then investigated the event using both the Activity Log and the Azure Monitor Alerts blade. This workflow mirrors a real-world incident response scenario where an unexpected resource deletion needs to be traced back to a specific identity and time.

What I Did

  • Opened Azure Monitor and navigated to Alerts to create a new alert rule
  • Scoped the alert rule to the subscription level and selected "Delete Virtual Machine" as the signal condition from the Virtual Machines signal list
  • Named the alert rule "vm-delete-alert" and created it
  • Triggered the alert by navigating to Virtual Machines, selecting the lab VM, and confirming deletion
  • Waited approximately five minutes for the alert to propagate, then opened Activity Log
  • Filtered the Activity Log by resource type "Virtual machines" and located the VM deletion event with a Succeeded status
  • Reviewed the event details in Activity Log, including the affected resource, timestamp, and initiating identity
  • Opened Azure Monitor Alerts and selected the fired vm-delete-alert to review the alert details, confirming the affected resource, time of event, and who initiated the deletion — demonstrating how this data supports incident investigation
