Overview

Azure Cloud Shell is a browser-based terminal that provides instant access to both Azure CLI and Azure PowerShell without requiring any local installation. In this lab, I configured Cloud Shell with a dedicated storage account, ran Azure CLI commands to list resources and create a Linux VM, switched to Azure PowerShell cmdlets to list and manage resources, and removed the VM using PowerShell — covering the full Cloud Shell workflow in both scripting environments.

What I Did

  • Launched Cloud Shell in PowerShell mode from the Azure portal, created a new storage account and file share (cloudshell) in the lab resource group to persist the session
  • Ran Azure CLI commands to list resource groups, storage accounts, and virtual machines: 
    az group list
az storage account list
az vm list
  • Created a Ubuntu 24.04 Linux VM named LabVM using Azure CLI with SSH key generation and a Standard public IP: 
    az vm create `
--resource-group "<RG_NAME>" `
--name LabVM `
--image Ubuntu2404 `
--size Standard_B1ms `
--admin-username azureuser `
--generate-ssh-keys `
--public-ip-sku Standard
  • Switched to Azure PowerShell cmdlets and listed resource groups, storage accounts, VMs, and all subscription resources: 
    Get-AzResourceGroup
Get-AzStorageAccount
Get-AzVM
Get-AzResource | ft
  • Removed LabVM using PowerShell and confirmed deletion by verifying Get-AzVM returned no results: 
    Remove-AzVM -Name LabVM -ResourceGroupName "<RG_NAME>"
