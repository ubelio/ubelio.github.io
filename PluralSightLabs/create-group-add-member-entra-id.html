Overview

Microsoft Entra ID security groups centralize permission, license, and role assignments for collections of users. In this lab, I acted as the director of a new internship program and set up the identity infrastructure to support it: creating a security group for the program, adding an existing user as a member, creating a new mentor user, and assigning that user as the group owner — establishing both member and ownership roles within a single group.

What I Did

  • Verified the pre-existing Cloud Student user was present in the Microsoft Entra ID Users list
  • Created a new Security group named "Internship Program" with a descriptive group description covering both mentors and mentees
  • Added the Cloud Student user as a member of the Internship Program group and confirmed the membership appeared in the Members blade
  • Created a new user with UPN "cloudinternmentor" and display name "Cloud Intern Mentor", then verified the user appeared in the All Users list
  • Navigated to the Internship Program group's Owners blade, added Cloud Intern Mentor as a group owner, and confirmed ownership was assigned — establishing a distinct member and owner structure within the same group
