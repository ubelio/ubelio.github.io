Overview

Azure Virtual Networks are the foundational building block for private networking in Azure, enabling resources such as virtual machines to communicate securely with each other, the internet, and on-premises networks. In this lab, I created a virtual network (vnet1) with a default address space of 10.0.0.0/16, confirmed the automatically provisioned default subnet, and added a second subnet (ServerSubnet) at 10.0.1.0/24 to prepare the network for additional resource deployments.

What I Did

  • Created a virtual network named vnet1 using the existing resource group and region defaults, with a 10.0.0.0/16 address space
  • Confirmed Azure's automatic provisioning of a default subnet at 10.0.0.0/24 during VNet creation
  • Added a second subnet named ServerSubnet with the 10.0.1.0/24 address range via the Subnets blade
  • Verified both the default and ServerSubnet subnets appeared in the subnet list for vnet1, confirming the network was ready for VM and service deployments
