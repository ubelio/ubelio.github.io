Lab 7 – Retention Policies

MS-102: Microsoft 365 Administrator Essentials

Overview

Created and configured retention policies and retention labels in Microsoft Purview to enforce data lifecycle governance across Exchange, SharePoint, OneDrive, and Teams — using both the official GitHub lab and supplemental Microsoft Learn exercises.

Tasks Completed

  • Created a tenant-wide retention policy covering Exchange mailboxes, SharePoint sites, and OneDrive accounts
  • Configured a separate retention policy for Teams channel messages with a shorter retention period
  • Created retention labels with specific retain-then-delete lifecycle settings
  • Published retention labels via a label policy targeted to pilot project users
  • Configured an auto-apply retention label policy based on sensitive information type detection
  • Created and published additional retention policies and labels via Microsoft Learn interactive exercises
  • Reviewed retention policy status and verified coverage across workloads in the Purview compliance portal

Source Material

Completed using Lab 7 – Exercise 1 from the MS-102T00 MicrosoftLearning GitHub repository; and Microsoft Learn exercises Implement Retention Policies, Implement Retention Labels, Create a Retention Policy, and Create a Retention Label. All steps were executed in a personal, paid Microsoft 365 test tenant.
