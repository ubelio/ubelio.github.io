Lab 9 – Sensitivity Labels

MS-102: Microsoft 365 Administrator Essentials

Overview

Created sensitivity labels with encryption and visual marking settings in Microsoft Purview, then published them through label policies so that pilot project users could classify and protect Microsoft 365 content.

Tasks Completed

  • Created a Confidential sensitivity label with content markings (header and footer) and no encryption
  • Created a Highly Confidential sensitivity label with encryption restricting access to specific users and groups
  • Configured encryption permissions: co-author access for internal users, viewer access for external recipients
  • Added a watermark visual marking to the Highly Confidential label definition
  • Created a sensitivity label policy and published both labels to the M365 pilot project group
  • Verified that labels appeared in Microsoft Word and Outlook for scoped users
  • Applied a sensitivity label to a test document and confirmed encryption and visual markings applied correctly

Source Material

Completed using Lab 9 – Exercise 1 from the MS-102T00 MicrosoftLearning GitHub repository. All steps were executed in a personal, paid Microsoft 365 test tenant.
