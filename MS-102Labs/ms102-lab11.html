Lab 11 – Authentication Methods

MS-102: Microsoft 365 Administrator Essentials

Overview

Configured Microsoft Entra authentication methods including MFA, self-service password reset, and passwordless options, then verified the combined registration experience for pilot project users.

Tasks Completed

  • Reviewed the Authentication Methods policy in the Microsoft Entra admin center
  • Enabled and configured Microsoft Authenticator as an allowed MFA method
  • Configured FIDO2 security key settings within the Authentication Methods policy
  • Enabled Temporary Access Pass for initial passwordless onboarding scenarios
  • Reviewed combined security information registration settings for MFA and SSPR
  • Tested the user registration flow for MFA via the combined registration portal
  • Reviewed authentication method usage and registration reports in the Microsoft Entra admin center

Source Material

Completed using Configure Authentication Methods from Microsoft Learn. All steps were executed in a personal, paid Microsoft 365 test tenant.
