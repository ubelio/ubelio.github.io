Lab 2 – Roles, Monitoring & Microsoft 365 Apps

MS-102: Microsoft 365 Administrator Essentials

Overview

Managed Microsoft 365 administrative roles and compliance role groups, monitored tenant health and activity, and configured Microsoft 365 Apps deployment settings.

Tasks Completed

  • Reviewed built-in Microsoft 365 admin roles and assigned roles to pilot project users
  • Created and managed role groups in the Microsoft Purview compliance portal
  • Monitored Microsoft 365 service health and reviewed active incidents and advisories in the admin center
  • Configured service health notification preferences and activity-based alert policies
  • Reviewed Microsoft 365 adoption and usage reports in the admin center
  • Configured Microsoft 365 Apps update channel settings and deployment preferences

Source Material

Completed using Exercise 1, Exercise 2, and Exercise 3 from the MS-102T00 MicrosoftLearning GitHub repository. All steps were executed in a personal, paid Microsoft 365 test tenant.
