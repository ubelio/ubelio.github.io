Lab 8 – Data Loss Prevention

MS-102: Microsoft 365 Administrator Essentials

Overview

Created Data Loss Prevention policies in Microsoft Purview to detect and restrict sharing of sensitive financial information, then validated policy enforcement through controlled test scenarios.

Tasks Completed

  • Created a DLP policy using the built-in Financial Data template targeting credit card numbers and bank account information
  • Configured the policy to apply across Exchange, SharePoint, OneDrive, and Microsoft Teams
  • Set the initial policy mode to Test with policy tips enabled to baseline behavior before enforcement
  • Configured user notification messages and admin alert thresholds within the policy
  • Tested the policy by attempting to send email containing sensitive financial data
  • Reviewed DLP alert reports and policy match activity in the Microsoft Purview compliance portal
  • Switched policy mode to Enforce after validating test results and reviewed the enforcement impact

Source Material

Completed using Exercise 1 and Exercise 2 from the MS-102T00 MicrosoftLearning GitHub repository. All steps were executed in a personal, paid Microsoft 365 test tenant.
