Lab 3 – Identity Synchronization

MS-102: Microsoft 365 Administrator Essentials

Overview

Prepared an on-premises Active Directory environment for cloud synchronization and deployed Microsoft Entra Connect to establish hybrid identity, then verified that on-premises accounts appeared correctly in Microsoft Entra ID.

Tasks Completed

  • Configured a routable UPN suffix in on-premises AD DS and updated user account UPN values to match
  • Validated that on-premises user accounts met synchronization prerequisites
  • Installed Microsoft Entra Connect using Express Settings on the on-premises server
  • Reviewed synchronization options including password hash sync and seamless SSO
  • Initiated the first synchronization cycle and monitored progress in the Synchronization Service Manager
  • Verified that on-premises accounts appeared as synced identities in the Microsoft 365 admin center and Microsoft Entra admin center

Source Material

Completed using Exercise 1 and Exercise 2 from the MS-102T00 MicrosoftLearning GitHub repository. All steps were executed in a personal, paid Microsoft 365 test tenant.
