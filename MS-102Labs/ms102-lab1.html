Lab 1 – Tenant Initialization, Users, Groups & Domain

MS-102: Microsoft 365 Administrator Essentials

Overview

Set up the foundational configuration of a Microsoft 365 tenant, including organization profile settings, audit logging, Information Rights Management, and PowerShell tooling. Created and managed user accounts, Microsoft 365 groups, a security group, and added a custom domain.

Tasks Completed

  • Configured the M365 organization profile: name, address, language, and targeted release preferences for select users
  • Enabled Information Rights Management (IRM) for SharePoint Online via the classic SharePoint admin center
  • Installed the Microsoft Graph PowerShell module and set execution policy to RemoteSigned
  • Enabled unified audit logging via Exchange Online Management module (Set-AdminAuditLogConfig -UnifiedAuditLogIngestionEnabled $true)
  • Created the Holly Dickson Global Administrator account; freed up licenses by unassigning them from an existing user
  • Created a custom M365 theme for the pilot project group to display the signed-in user's name in the header band
  • Created Microsoft 365 groups: M365 Pilot Project, Inside Sales, and Accounting — with assigned owners and members
  • Created the IT Admins security group and added administrative personnel as members
  • Deleted the Inside Sales group and restored it using Microsoft Graph PowerShell (Restore-MgDirectoryDeletedItem)
  • Added a custom domain to the Microsoft 365 tenant and validated DNS records

Source Material

Completed using Exercise 1, Exercise 2, and Exercise 3 from the MS-102T00 MicrosoftLearning GitHub repository. All steps were executed in a personal, paid Microsoft 365 test tenant.
