Copilot Studio Agent Academy

Free, open-source training program by Microsoft — build real agents with Microsoft Copilot Studio

The Copilot Studio Agent Academy is a structured, badge-earning program published by Microsoft that teaches agent development from the ground up. It covers two progressive rank courses, standalone Special Ops missions targeting specific skills and integrations, and a Cowork Collective track focused on Copilot Cowork inside Microsoft 365. Each completed lab or course earns a verified digital badge issued by the Global AI Community.
