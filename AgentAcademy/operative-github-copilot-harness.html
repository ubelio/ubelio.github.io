Overview

Hands-on course building a multi-agent hiring system in the new Microsoft Copilot Studio experience, running on the GitHub Copilot harness. The finished system combines skills, the Microsoft Dataverse MCP server, connected agents, and workflows, with resume intake, weighted role matching, safety controls, human oversight, and evaluations. Reuses the classic Operative hiring scenario to show what the new building blocks replace.

What I Built

  • Imported the hiring data model and created the central Hiring Agent orchestrator
  • Authored agent instructions and a reusable skill, and added the Dataverse MCP server
  • Added a published connected Interview Agent grounded through the Dataverse MCP server
  • Selected the model, shaped responses, and tested moderation, guardrails, and AI disclosure
  • Built resume intake and weighted role matching that creates Job Applications
  • Built a Python skill that generates an interview-prep Word document
  • Built an email-triggered workflow that screens the inbox and files resumes and their PDFs
  • Added an inline agent and the published Hiring Agent to the workflow, with Teams notifications
  • Added human review, alternate flows, observability, and a regression pass
  • Enabled Work IQ so the Interview Agent can read calendars and book a supervised meeting
  • Ran evaluation sets, published to Microsoft 365 Copilot and Teams, and configured Monitor
