Overview

Mission grounding a Copilot Studio agent in its own documents using Retrieval-Augmented Generation with Azure AI Search vector search. Candidate resumes are vectorized and wired into an HR Knowledge Agent as a connector tool, so it answers by meaning with document-backed citations.

What I Built

  • Created an Azure AI Search service, an Azure Storage account, and a text embedding model deployment
  • Uploaded sample resume PDFs to Blob Storage and built a vector index with integrated vectorization
  • Built an HR Knowledge Agent on the GitHub Copilot harness with instructions to retrieve and cite sources
  • Connected Azure AI Search as a connector tool (Semantic Hybrid Search), since it isn't a Knowledge source on this harness
  • Tested semantic and multi-criteria queries with document-backed citations
