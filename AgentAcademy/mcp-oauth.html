Overview

Mission connecting a secured MCP server protected by OAuth 2.0 authorization to a Copilot Studio agent on the GitHub Copilot harness. Covers Microsoft Entra ID app registrations, the authorization code flow, and authenticated tool use.

What I Built

  • Configured a .NET HR MCP server that validates OAuth 2.0 JWT bearer tokens
  • Registered backend API and client applications in Microsoft Entra ID with an exposed scope, delegated API permissions, and admin consent
  • Exposed the MCP server through a dev tunnel and updated the Application ID URI
  • Built a Copilot Studio agent on the GitHub Copilot harness and registered the secured server as an MCP tool using the OAuth 2.0 authorization code flow
  • Tested authenticated calls to the five HR candidate tools and confirmed token validation on the server
