Overview

The Recruit course is the entry point to the Copilot Studio Agent Academy — a 13-mission, hands-on program that takes you from zero to building and publishing a fully functional IT helpdesk agent using Microsoft Copilot Studio's standard (topic-based) harness. The course uses a realistic IT help desk scenario throughout so every concept is immediately grounded in a real use case. By the end, you have gone through the complete agent development lifecycle: environment provisioning, agent creation, conversation design, SharePoint knowledge grounding, flow automation, declarative agent deployment for Microsoft 365 Copilot, and production publishing to Teams — and understand how Copilot Studio licensing and Copilot Credits billing work before agents go live.

What I Built

  • Built an IT helpdesk agent in Copilot Studio grounded on a SharePoint knowledge source and IT policy documentation, enabling the agent to answer questions from live organizational content rather than generic training data.
  • Designed conversational topics with triggers, branching nodes, and intent matching to handle device requests and IT support queries — covering both informational and task-execution topic types.
  • Created Adaptive Cards using JSON payloads and Power Fx formulas to replace plain-text prompts with structured, interactive input collection inside the agent conversation.
  • Built an agent flow that fires on device request submission: retrieves the selected device record from a SharePoint list and sends an automated notification email to the user's manager, completing an end-to-end approval initiation without leaving the agent.
  • Configured event triggers to enable autonomous agent actions that execute on a schedule or system event without requiring active user input.
  • Deployed a declarative agent targeting Microsoft 365 Copilot, customizing the M365 Copilot experience with scoped instructions, tools, and knowledge for the IT help desk use case.
  • Published the completed agent to Microsoft Teams and Microsoft 365 Copilot channels, making it available to end users in the interfaces where they already work.
  • Packaged all agent components — agent definition, flows, uploaded files — inside a Power Platform solution to enable ALM practices: version control, environment promotion (dev → test → production), and repeatable deployment.
  • Studied Copilot Studio licensing models, Copilot Credits consumption across deployment scenarios (internal, external, automated), and how to estimate and monitor usage costs before agents go live at scale.
