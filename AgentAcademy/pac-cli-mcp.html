Overview

Starting with version 1.44, the Power Platform CLI ships with a built-in Model Context Protocol (MCP) server — a direct communication channel between AI assistants and Power Platform environments. This mission configures that built-in server and connects it to MCP-compatible AI tools, most notably VS Code Copilot. Once wired in, Power Platform operations that previously required memorizing CLI syntax or navigating the admin portal can instead be issued as plain-language instructions through the AI assistant. This is a practical demonstration of how MCP turns existing developer tooling into AI-addressable interfaces without rebuilding the tools themselves.

What I Built

  • Installed the Power Platform CLI globally and activated its built-in MCP server, making Power Platform operations available as AI-callable tools.
  • Connected the pac MCP server to VS Code Copilot and verified natural-language command execution across the CLI's core operation areas.
  • Issued environment lifecycle commands, authentication profile management, Dataverse operations, and solution import/export using natural-language prompts through the MCP interface — no CLI syntax required.
  • Explored the full scope of CLI coverage: environments, authentication, Dataverse tables, solution packages, Power Pages, and PCF custom controls.
