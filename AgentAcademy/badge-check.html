Overview

Mission using Copilot Cowork to analyze building badge scan data, identify employees who repeatedly forget to badge out, and email a report. Starts with a plain summary report, then upgrades it to a styled HTML report by adding a custom skill stored in OneDrive.

What I Built

  • Analyzed a badge scan CSV with Copilot Cowork to find employees with missing checkout records
  • Emailed a summary report of missed checkouts by employee, badge ID, and office
  • Created a custom frontend-design skill (SKILL.md) in OneDrive for Copilot Cowork to discover
  • Generated a styled, responsive HTML report ranking the top 10 offenders with miss rates, highlighting anyone above 50%
  • Compared the plain and skill-formatted reports to see how a single skill file changes the output
